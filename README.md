## ✨ Fitur Utama

### 1. 📖 VRTL Bento Glassmorphism Planner (Pastel Frosted Glass)
- **🎯 Today's Goals (Pink Glass)**: Checklist bulat pink, inline quick-add goal, ikon hati.
- **😊 Mood Tracker (Purple Glass)**: 4 pilihan mood interaktif (`Happy`, `Chill`, `Tired`, `Cool`) dengan reward XP harian.
- **☑️ To Do List (Lavender Glass)**: Checklist kotak rounded ungu dengan drag handle `:::`.
- **⭐ Priority (Mint Glass)**: Daftar tugas dengan prioritas tinggi.
- **📅 Appointments (Peach Glass)**: Jadwal janji temu spesifik jam & ikon agenda.
- **📝 Notes & Thoughts (Sky Blue Glass)**: Area catatan auto-save lengkap dengan stiker kelinci imut 🐰 + hati 🩷.

### 2. 📱 iOS 18 Pro Max Design & Dynamic Island
- **Dynamic Island**: Notch interaktif yang menampilkan live timer dan soundwave beranimasi saat sesi fokus berjalan.
- **Top Bar**: Status jam real-time, Wi-Fi, sinyal, baterai, notifikasi bell dengan badge merah, dan profile avatar.
- **Capsule Navigation**: `Today`, `Planner`, `Focus`, `Goals`, `Stats`, `Store`.
- **Bottom Glass Dock**: Floating capsule dock dengan efek neon pink glow pada tombol aktif.
- **Zero Horizontal Overflow**: 100% responsif dan teruji rapi di Android maupun iPhone tanpa bug geser/overflow ke samping.

### 3. 🎮 Real Gamification & Anti-Cheat Engine
- **XP, Level, Coins & Gems**: Setiap penyelesaian tugas memberikan XP dan Koin.
- **Anti-Cheat Lock**: Melindungi dari spamming/cheat klaim berulang kali menggunakan atomic locking dan cooldown persisten di `localStorage`.
- **Circular Pomodoro Focus Timer**: Sesi 25m Pomodoro, 5m Break, 50m Deep Work dengan animasi lingkaran SVG dan Web Audio API synthesizer.
- **RPG Adventure Map & Boss Battles**: Perjalanan level 1 hingga Final Boss.
- **Store & Self-Reward**: Belanjakan koin untuk booster dan reward nyata.

## 🚀 Cara Menjalankan Secara Lokal

1. Clone repository ini:
   ```bash
   git clone https://github.com/voltakyy/vrtl-studyquest.git
   ```
2. Buka folder proyek:
   ```bash
   cd vrtl-studyquest
   ```
3. Langsung buka file `index.html` di browser favoritmu (Google Chrome, Safari, Edge, dll) atau gunakan Live Server:
   ```bash
   # Menggunakan Python simple server (opsional)
   python -m http.server 3000
   ```
   Lalu buka `http://localhost:3000` di browsermu.
